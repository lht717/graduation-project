## 项目架构与数据流

```
┌─────────────────┐     .ply / glTF      ┌──────────────────┐
│  3D 重建组（上游） │ ───────────────────▶ │  平台后端（卓奕臻） │
└─────────────────┘                      │  模型存储/URL/API │
                                         └────────┬─────────┘
                                                  │ 实验列表 / 模型 URL / 调度状态
                                                  ▼
                                         ┌──────────────────┐
                                         │ 平台前端（林晶晶） │
                                         │ 页面框架/路由/布局 │
                                         │  ┌────────────┐  │
                                         │  │ 3D 可视化模块 │◀─┼── 李宏韬（provide 注入）
                                         │  └────────────┘  │
                                         └──────────────────┘
```

- **上游**：重建组产出 `.ply`（3DGS）与 glTF（网格）模型文件
- **后端**：卓奕臻负责模型存储与 API（实验列表、模型 URL、算法调度）
- **平台前端**：林晶晶负责整体页面；李宏韬的 3D 可视化模块通过 Vue `provide/inject`（`threeDgsRenderer`）嵌入

## 各子任务需求

### 平台后端（卓奕臻）

- 管理员、用户、实验室管理
- 算法调度
- 提供 API：实验列表、模型 URL、算法调度状态
- 模型信息接口暂定 `/api/models/:id`，字段待与前端对齐

### 平台前端（林晶晶）

- 平台整体框架：路由、布局、导航
- 用户页面（普通用户与管理员均可访问）
- 模型可视化页面 `VisualizationView.vue`：模型 ID 加载、信息面板、资源地址展示
- 预留 3DGS 渲染区域，通过 `app.provide("threeDgsRenderer", ThreeDgsRenderer)` 注入渲染器
- 生产构建验证通过（模拟 API）

### 3D 可视化前端（李宏韬）

- 浏览器内 3DGS 实时光栅化渲染（.ply）
- 相机交互：旋转 / 缩放 / 平移
- 多模型切换、加载进度（大模型流式加载）
- 模型信息面板、点击拾取（点选场景物体获取信息）
- 双格式渲染：.ply（3DGS）与 glTF（网格）同场景共存
- 性能要求：大点数模型流畅帧率、显存/内存管理
- 兼容性：WebGL2 兜底 + WebGPU 渐进增强

## Git 协作约定

- 主分支 `main`，各成员在各自目录内开发，避免冲突
- 开发前先 `git pull`，提交前自测通过
- 提交信息用中文，格式：`[模块] 简述本次改动`，如 `[viewer] 跑通 .ply 单模型渲染`
- **大模型文件（.ply / glTF）不提交到仓库**，通过文件服务器或 Git LFS 共享
- 环境变量、构建产物（node_modules / dist）不进仓库
